# Hang Liu's Arcade — CS5610 Project 1

A four-page static portfolio and mini crossword built for CS5610 Web Development, Fall 2026.

## Pages
- `/` — landing page
- `/game/` — CSS Grid mini crossword
- `/about/` — education and professional profile
- `/contact/` — professional contact page

## Technical constraints
This project intentionally uses only HTML and CSS. There is no JavaScript, CSS framework, component library, or runtime dependency.

## Before submission
1. Replace placeholder email, GitHub, and LinkedIn information in `contact/index.html`.
2. Validate every HTML page with the W3C HTML validator.
3. Run Lighthouse on the deployed site and save a screenshot showing the accessibility score.
4. Test keyboard navigation and widths of 320px and 864px.
5. Publish the repository and enable GitHub Pages.

## Local preview
Open `index.html` in a browser, or use any static local web server.
